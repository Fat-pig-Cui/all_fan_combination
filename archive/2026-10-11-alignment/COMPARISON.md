# 四麻普通役组合修正后对比报告（已归档）

更新日期：2026-10-11。

`all_yaku_combos` 已根据理论依据修正，当前两仓库均为 **20,687种：门清15,270种，副露5,417种**。
不仅总数相同，按“门清性＋完整计分役集合”逐条比较，两边独有集合、番数不一致记录均为 **0**；20档逐番分布与17个专题的门清／副露分布全部一致。

## 一、修正方法

首次比较发现的差异与当时数据保留在 [初次报告](COMPARISON_INITIAL.md) 和 [修正前机器数据](comparison-initial.json)。
旧仓库的基础分组表仍作为理论来源。本次补齐遗漏组合、修正条件限制，再由旧仓库自己的工具展开白发中、门风场风、必带役和条件状态，生成完整标准化集合。
该展开不导入本仓库的结果、求解器或判役器，因此没有直接用本仓库结果替换手工表。

旧仓库同步修正了基础牌例、受限表、16个辅助计算脚本、总计脚本、专题说明和首页。
已明确的修正包括：算术多计110、遗漏一杯口混全混色401、遗漏混老头混色多役牌176、其他部分条件展开多计210，以及七对子断幺清一色择优排除17。

本仓库的判役算法、可达性模型和20,687种快照均未因本次对齐而改动。

## 二、原先未对齐部分的研究结果

| 原未对齐项 | 相对原表的理论修正 | 具体原因 |
|---|---:|---|
| 门清断幺九 | −3 | 三色同顺＋一杯口占满四个顺子，不能暗杠岭上 |
| 门清平和 | +17 | 补入平和混全三色20种；排除清色纯全一杯平和的抢杠3种 |
| 门清清一色，扣除原算术错误后 | −9 | 一气／纯全等三种基础集合无法杠，不能共用抢杠和岭上表 |
| 门清纯全 | −3 | 三色同顺＋一杯口占满四个顺子，不能岭上 |
| 门清三色同刻 | −15 | 不带三暗刻的门清三色同刻只能荣和补刻子，不能沿用自摸或抢杠展开 |
| 副露小三元 | +51 | 补入混老头混色及风役48种；抢杠表漏列三杠双风混全混色3种 |
| 副露清一色 | −2 | 清色一气与清色纯全无法杠，不能岭上 |
| 副露三色同刻 | +4 | 8番基础表两行只计1，修正后连同三种偶然役增加4 |
| 副露三杠子 | −56 | 抢杠表只排除对对，遗漏副露三暗也不能抢杠 |
| 合计 | −16 | 与首次报告中已解释的+240合计为原总差+224 |

平和脚本另把三种增加4番的条件写成增加3番，已修正对应分布，不影响总数。
副露三杠基础表重复写“三暗”的笔误也已改为“混色”。

这些修正都有结构理由，不是由净差反推数量：四个面子全为顺子就没有杠位置；清一色一气已使用全部九种牌，任意杠都会超过四张；抢加杠的和牌张必须在完成手牌中恰有一张；荣和补成刻子不再计作暗刻。

旧仓库根目录的 `CORRECTIONS.md` 保存完整推导和牌例。例如东家东场，大明杠东、暗杠白与发，手牌 `23p 77z` 抢加杠 `1p`，可成立小三元、三杠、双风、混全、混色等12番，而没有三暗刻；该遗漏牌例已通过当前判役器复算。

## 五、数据与复算

归档机器数据为 [comparison.json](comparison.json)，包含全量集合对比结果、逐番与专题数组、当时源码和快照摘要。修正前数据单独保留，不被零差异覆盖。归档记录用于保存本次结论；后续复算应写入独立的本地文件。
