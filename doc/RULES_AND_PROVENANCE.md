## 三麻配置来源

三麻立直须至少剩3张通常牌，由用户于2026-10-11明确确认；四麻配置仍为4张。配置、规则指纹和这一证据边界保存在源码与各自结果汇总中。
支付层的三麻自摸损不改变普通役集合，本次不枚举支付金额；拔北宝牌与其他悬赏牌也不进入组合或拆分择优。
三麻验证为输入边界、独立判役、结构求解与全部见证复算；已有JavaScript对照报告仍仅针对四麻，不冒充三麻计分对照或服务器验证。

主要参考点：

- 普通役番数及副露食下、下位役排斥。
- 自然役满与普通役分开处理。
- 平和20符自摸、七对子25符、门清荣和与面子／雀头／待牌符。

独立实现的明确选择：

- 和牌张归属到具体未固定面子或雀头，逐项计算该解释的待牌类型。
- 全部拆分中成立的自然役满优先于普通役与宝牌。
- 普通手完全同基本点、同原始番数、同符时保留全部不同役集合，而不是依赖参考DFS的首次命中。
- 自然役满不使用符，其输出符统一为0；参考国士分支可能保留25，这不影响役满倍数或支付。
- 宝牌在枚举中完全排除；独立判役接口支持另传总悬赏番，不自动计算指示牌和赤牌数量。

## 规则基线

本项目参考 `MahjongSkills` 规则文档。

对应正文为 `references/topics/03-yaku-han.md`、`04-scoring.md`、
`07-edge-cases.md` 和 `09-call-kan-rules.md`。
本模型采用的立直后暗杠限制是“包含刚摸到的第四张、完整听牌种类不变”，
不另外要求面子解释完全不变。
振听的舍牌与响应范围由用户于2026-10-11补充确认：暗杠、加杠、拔北的牌不纳入舍张振听，放过这些操作的和牌响应不新增振听。结合既有规则，已有振听仍限制抢杠和抢北；已被鸣走的原始舍牌及其见逃事实仍须保留，不能只按最终可见牌河判断。该补充没有改变当前存在性模型的组合约束；不作为本项目执行的服务器验证。
运行不依赖该外部文档仓库；实际编码的规则、参数和理论边界均记录在本仓库的README、`THEORY.md`和源码中。

立直余牌不少于4张作为本模型明确的理论参数，写入每次结果的 `scope` 与条件证书。
它支持普通立直一发海底，并排除一发河底；若修改这一参数，需要重新枚举。
这不是本项目执行的服务器验证结论。

## 人工参考仓库

本项目是对 [all_yaku_combos](https://github.com/Fat-pig-Cui/all_yaku_combos) 人工分类方案的独立计算实现。
参考仓库的统计表和冲突表不作为枚举器输入，也不作为目标总数。

2026-10-11修正：此前关于“双立直不自动排斥抢杠”的推导错误。`examples/double_riichi_chankan.json` 是应被拒绝的历史反例，当前算法与相关测试已修正：

```text
和牌前：12m 123p 123s 456s 77p
和牌张：3m，双立直，抢杠，非一发
```

第一舍牌前无人鸣牌，先双立直；之后别家打出3m，对手取得该舍牌形成碰。该3m已经是立直者的待牌，立直者若不立即荣和，就因放过这张普通舍牌进入立直后永久振听，不能再抢剩余3m的加杠。造成振听的是碰的原始来源舍牌，不是后来的加杠响应。牌张上限与最终判役均成立，仍不能证明过程合法。

本地参考计算器只读取最终牌面和条件标志，也可能算出该组合；这一对照只能验证计分一致，不能验证操作过程与振听。当前发布的四麻快照为20,687种组合，并由当前求解器确认剩余约束无解。

## 一、审查范围与方法

2026-10-11对照[all_yaku_combos](https://github.com/Fat-pig-Cui/all_yaku_combos)的主冲突表、条件役专题，以及门清／副露专题中的“无法抢杠”“双碰荣和”等说明，审查四麻普通役枚举。

本次检查旧快照全部21,179条记录，对照95条两役互斥关系，另检查19项组合限制，并执行16项针对性求解检查。原仓库保持不变；审查没有使用服务器或客户端验证。

这些检查覆盖已列出的规则，不等于证明所有高阶组合及操作时序均无遗漏。

## 二、应保留的规则清单

| 注意事项 | 当前实现方式或检查要求 |
|---|---|
| 雀魂振听的舍牌与响应范围 | 按舍牌记录及舍牌见逃判定；暗杠、加杠、拔北的牌不纳入舍张振听，放过这些响应也不新增振听。已有振听仍限制抢杠、抢北 |
| 双立直与普通抢杠不能复合 | 双立直前不能有碰；之后放过形成该碰的原始待牌舍牌会导致永久振听，牌被碰走不撤销见逃。模型、判役和条件证书均应拒绝 |
| 国士可以抢暗杠 | 保留自然役满特例，但不将双立直或抢杠普通役计入结果 |
| 抢杠不能与七对子、对对和、混老头、二杯口复合 | 普通抢加杠要求和牌者完成手牌中该牌只有一张，另外三张由对手的碰占用 |
| 副露抢杠不能与三暗刻复合 | 根据和牌张归属及固定面子明暗状态判断，不能只数最终刻子 |
| 四麻岭上不能与平和、七对子、二杯口复合 | 四麻必须有已声明的杠；三麻拔北须作为独立补牌来源扩展 |
| 门清对对和自摸成为四暗刻 | 自然役满优先，排除普通役解释；门清对对和的普通荣和应有三暗刻 |
| 双立直、一发、三杠子不能同时成立 | 双立直前不能开杠，之后的杠中断一发 |
| “双碰荣和”涉及暗刻数变化 | 荣和补成的刻子不算暗刻，自摸时要重新判定完整役集合，不能沿用荣和组合 |
| 小三元必须伴随两种三元牌役 | 统计完整役集合，不省略伴随役 |
| 二杯口不叠加一杯口 | 同一解释内处理上下位关系 |
| 七对子与一般形可能重叠 | 枚举全部合法拆分、和牌张归属后择优，不能拼接不同解释的役 |
| 役牌与平和、断幺九的冲突 | 按具体牌种、自风、场风和雀头判断；白发中以及门风场风分别编码 |
| 食下可能影响竞争解释 | 使用实际门清／副露番数比较；不能把门清解释的番数套到副露状态 |
| 抢杠、岭上、海底、河底互斥 | 用唯一和牌事件及荣和／自摸限制表达 |
| 每种牌至多四张 | 包含手牌、固定杠的实际四张及抢杠所需的对手牌张资源 |
| 合法暗杠不必保持同一面子拆法 | 立直后须使用刚摸的第四张，并保持完整听牌种类；不能额外要求解释不变 |
| 宝牌不是役 | 本次组合及拆分择优均不计宝牌；单有宝牌不能提供和牌资格 |

## 三、已确认错误与修正

原条件证书把“宣告双立直后，对手碰出待牌，再加杠被抢”当作合法过程，漏掉立直后放过形成该碰的原始待牌舍牌造成的永久振听。旧快照有492种组合受影响，全为门清组合。

2026-10-11已修正结构约束、标准形判役、普通役条件证书，以及三个原本错误接受该组合的测试。普通立直及一发抢杠仍保留；自然役满中的国士抢暗杠也保留。

结果更新不能只做减法或替换源码摘要。应重新判定旧记录，在当前约束下排除已确认组合与已证伪的具体候选，再让求解器检查剩余空间；只有返回`unsat`才确认完整。

本次已重新检查21,179条旧组合见证和5,474条旧拒绝候选，当前求解器最终返回`unsat`，没有发现额外组合。修正结果为20,687种：门清15,270种、副露5,417种。77项单元测试、当前全部见证复算与快照摘要检查用于验证本次修正。

### 2026-10-11振听响应范围补充

用户确认：已经碰6m后，另一家非振听普通立直听3m、6m；放过6m加杠不会新增振听，之后仍可荣和他家打出的3m。暗杠、加杠、拔北都不能按普通舍牌见逃处理；已有振听与一发中断仍须独立检查。

当前模型寻找至少一个合法过程，没有将放过抢杠或抢北编码为新增振听；双立直抢杠的排除依赖原始舍牌，仍成立。此次修正说明，不改变约束或结果：四麻20,687种，三麻18,861种。判役接口没有完整舍牌与响应历史，不能将最终牌面接受或现有测试通过当作振听状态转换的验证。证据为用户确认与本地审查，未执行服务器验证。

## 四、尚需改善的验证边界

1. 独立判役接口的`legal_win`主要表示最终牌形及所给条件能计分，不是完整牌谱合法性验证。已知改变听牌的立直后暗杠由条件证书拒绝，独立判役仍可能给出分数；这不是当前枚举误收，但接口语义需说明。
2. 原独立判役接受北场，而段位枚举仅允许东、南、西场。现已统一段位配置：两种玩法场风均限定东、南、西；三麻自风不含北。扩展其他房规须使用独立配置。
3. 复算工具复用条件证书，双方共同遗漏的规则仍可能同时通过。旧仓库注意事项应作为独立检查依据，补充不能成立的反例。
4. 本地参考计算器只读取最终牌面与条件标志，不验证完整操作过程；计分对照一致不能证明非振听或可达。
5. 一发与末巡的结论依赖当前余牌门槛；三麻应按人数、拔北和事件顺序重新推导。

## 五、后续回归要求

至少覆盖：双立直普通抢杠被拒绝、普通立直一发抢杠仍可成立、国士抢暗杠仍可判定、立直暗杠前后完整听牌比较、旧互斥关系与伴随役检查，以及快照的全部见证复算。

求解器返回`unsat`只证明已编码模型中的剩余空间无解；哈希、单元测试、判役对照与复算分别支持各自的有限结论，不能代替规则覆盖审查。
