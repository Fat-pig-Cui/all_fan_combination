# 普通古役组合差量的复算

本目录在四麻段位的完整牌型模型上启用雀魂14种古役，枚举最终仍按普通役计番的完整役种集合。结论见上一级的差量报告；这里仅说明如何复算。

## 来源与口径

基础计番、牌型约束和行动条件证明来自 MIT 许可的 [all_fan_combination](https://github.com/Fat-pig-Cui/all_fan_combination)，复制时的版本为 `8c17095fe2ad4b336a306ebace9ef881eed116a0`。当前仓库的古役扩展位于上一级 `guyi/`；本目录只保留古役专用规则模块，许可证保留在本目录。`baseline/` 保存其四麻完整结果快照，基线共20,687种，门清15,270种、副露5,417种；快照自带未压缩内容的 SHA-256。

启用八种普通古役：燕返、杠振、十二落抬、五门齐、三连刻、一色三同顺、一筒摸月、九筒捞鱼。另外六种古役役满作为普通结果的排除条件，不能只在旧组合上追加普通古役。

一组结果按“门清／副露、完整役种集合”去重。宝牌不参与计数或分解择优；累计13番以上的普通组合保留，自然役满排除。场风取东、南、西，自风取东、南、西、北。古役的 fan ID 为51至64；位掩码的位序与 ID 无关，保留原有30位并追加八位普通古役。

## 算法与验证边界

1. 约束模型构造四面子一雀头或七对子的具体牌型，检查四枚上限、固定面子、和牌张、门清状态及条件役事件。
2. 同一副牌由独立计番器遍历全部合法分解，依次比较基本点、番数、符数，保留完全并列的解释。不得把三连刻分解和一色三同顺分解拼接，也不得忽略另一种分解中的自然役满。
3. 检查立直后暗杠的完整听牌集合不变等行动条件。燕返、杠振作为独立事件标志，可以同时成立；但二者均要求普通舍牌荣和，杠振打断一发。放铳者可以在较晚巡目暗杠后宣言普通立直，不要求开局首巡宣言。
4. 将牌型在其他合法立直、自摸／荣和、和牌时点下重算，可作为搜索种子。种子和中途结果均不能代替穷尽证明；只有剩余模型返回 `unsat` 才标为完成。
5. 对最终每一组示例再次重算，并与段位快照做集合差，生成新增、消失及不变的数量；压缩包中的完整差量可逐行核查。

模型使用计番支配剪枝：门清一色三同顺若第四组为刻子／暗杠，把九张顺子牌改拆为三连刻后，非单骑荣和至少有对对和、三暗刻、三连刻共6番；原顺子解释的一色三同顺3番，加上纯全带幺九也至多6番，同番时符数更低。单骑荣和或自摸则有四暗刻自然役满。因此最终选中的门清一色三同顺必为四顺子形。对于四顺子形，自摸或抢杠时还必须有二杯口、混全带幺九、纯全带幺九中的至少一种；否则三连刻加三暗刻的解释不劣于其番数，并以符数胜出。混全／纯全是必要保留的例外，因为改拆刻子会失去它们。副露情形不使用这些剪枝；独立计番器仍按全部分解重算。

分片驱动另加入两条必要条件。门清三连刻若既无三暗刻又无对对和，第四组只能是顺子；若没有暗杠固定牌形，将三个刻子改成三组同顺会至少增加1番，且原刻子解释至多50符，新顺子解释至少30符，因此即使未达封顶，新增一番也足以胜出。故这类最终结果必须有暗杠。另一个特例是三组连续刻子再加同起点顺子、共每种四张：没有固定暗杠时，改为四组相同顺子，二杯口加一色三同顺至少6番，胜过三暗刻加三连刻至多4番。两条都保留暗杠打断替代分解的例外。

人和不要求普通役枚举引入额外开局状态：同一普通牌型可安排在首次摸牌以后和牌。大七星原本即属字一色自然役满，因此不产生普通基线的额外排除。三种车轮牌形必须门清；石上三年则排除全部双立直加海底／河底的普通结果。具体消失数量以全量集合差为准，不能只统计旧示例被替换的数量。

这些检查证明的是所声明规则下的理论可实现性，没有进行服务器交叉验证。

## 运行方法

Python 3.9及以上。在本目录创建环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python enumerate_guyi.py --output results_reproduced
```

Windows 把 `.venv/bin/python` 换为 `.venv\Scripts\python.exe`。脚本不依赖外部源仓库路径。

中断后的续跑：

```sh
.venv/bin/python enumerate_guyi.py --output results_reproduced --resume
```

续跑要求枚举源文件 SHA-256 不变。每100个新模型、种子阶段每2,000条输入记录更新检查点；已写入的结果会恢复并阻止重复投影，中断前的拒绝候选可能需要重查。`--max-models` 可限制抽样模型数，此时结果不能当作最终数量。`--extra-seeds DIRECTORY` 可读取历史候选目录，候选始终按当前规则重新检查。

上一级的 `test_ordinary.py` 提供26项边界检查，其中一项比较80个约束模型与独立计番器。全量完成后，在仓库根目录运行 `guyi/ordinary_delta.py`，会验证全部最终示例、生成差量报告与压缩清单；该脚本默认读取本目录的 `results/`，尚未完成时会拒绝发布统计。

## 分片枚举

推荐在上一级目录使用 `enumerate_ordinary_sharded.py`，按最终计入的事件役集合分片搜索。每片只加入该片的已知组合阻止条件，减少大型投影排除表带来的开销。副露牌型没有门清自摸役时，不会仅凭示例自摸／荣和的不同而错误拆分；固定的是役种标志，不是某一份示例的动作记录。

```sh
ordinary/.venv/bin/python enumerate_ordinary_sharded.py --output ordinary/results
```

可以用 `--seed ordinary/历史结果目录` 读取已有候选；每条候选重新计番和检查行动条件。该驱动先单独验证“整个模型不属于任何分片”不可满足，再逐片搜索至不可满足；两项都完成才标记全量完成。驱动自身的 SHA-256 单独记录，`--resume` 同样要求源文件未变。两种驱动使用相同的牌型、计番、去重和搜索终止条件。

当前结果保留了继承分片所需的紧凑 `proof_parent/` 元数据。`--inherit` 只接受精确匹配的兼容驱动、核心源文件和已验证集合键；单独从头复算无需该继承路径。

最终结果和分片证明以 `results/` 为准，完整记录保存为 `results/records.zip`。公开仓库只保留压缩快照、摘要和当前证明元数据，展开的 JSONL 属于本地可再生中间产物。
